# ECG Leadwire Junction Box PCB Modification

## Project Overview

This project involved modifying the PCB layout of an ECG leadwire junction box used in a patient monitoring system, with a focus on dimensional adjustments and noise mitigation.

## My Contribution

- Modified the PCB dimensions to meet the mechanical requirements of the assembly.
- Implemented a GND-connected copper pour across the PCB to improve noise performance.
- Aimed to eliminate the need for additional external copper shielding around the board.

## Tools & Skills

- Altium Designer
- PCB Layout Modification
- Copper Pour and Grounding
- Noise Mitigation
- Medical Device Electronics

## Project Scope

The project focused on practical PCB layout improvements to simplify the physical implementation and address noise-related concerns in an existing medical device design.
